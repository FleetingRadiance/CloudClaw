# CloudClaw — 新一代企业级智能体平台 · AI 战略基座

> ⚠️ **说明**：本项目目前仅开放**前端代码**；如需获取**完整后端系统**，请**翻看至底部**获取。

---

## 项目简介

**CloudClaw 是面向企业的新一代智能体平台**，为企业提供**统一 AI 战略基座**，系统性解决 AI 应用零散建设、缺乏统筹的问题。

平台深度集成 **OpenClaw Skills 技能体系**，融合 **ReAct 智能推理框架**、**向量化知识库**、**沙箱隔离机制**，构建**智能对话、自定义技能、智能体管理、智能问数、知识库、定时任务、团队共享空间**七大核心模块，实现组织级智能能力的集约化构建与规模化赋能。

> **一句话定位**：为每一位员工配备专属 AI 助手——**把重复工作交给 AI，把经营洞察还给业务，把数据安全留在自己手里。**

## 核心价值

直击企业智能化转型六大核心痛点：

| 企业痛点               | CloudClaw 解决方案                            | 可量化收益                        |
| ---------------------- | --------------------------------------------- | --------------------------------- |
| AI 应用零散、各自为战  | **统一 AI 基座**，能力统一调度、复用、治理    | 告别"AI 烟囱"，能力集约化管理     |

| 周期性报表耗费大量人力 | **定时任务 + 文档生成**全链路联动             | 经营周报/月报**无人值守自动产出** |
| 知识沉淀于个人、难复用 | **私有知识库 + 团队共享空间**                 | 知识**资产化、可协同、可检索**    |

| 系统封闭、难以拓展     | **OpenClaw Skills + 自定义智能体**            | 按业务需求自由拓展                |

## 企业级核心能力

### 📄 文档自动生成

内嵌 Word / Excel / PPT / HTML 多格式生成引擎，采用「数据填充 + 模板渲染」自动化流程，一键输出经营周报、复盘报告、分析简报等规范文档。

> **效率提升**：数小时人工撰写 → **分钟级自动产出**

### 📊 智能数据查询分析

自然语言直连企业 BI 数据仓库与任意业务数据库（客流 / 业绩 / 会员 / 店铺 / 库存 / 订单 / 财务等），内置多维分析引擎自动完成**同比环比、趋势预测、归因分析**，输出可视化结论。

- **任意数据库接入**：自主配置 MySQL / BI 仓库等数据源，连接信息 AES-256-GCM 加密存储，读写权限分离
- **SKILL 驱动零配置**：无需预定义数据库元数据与字段字典，仅需撰写一个功能 SKILL 即可驱动全流程
- **业务自助**：非技术人员自然语言提问，**无需依赖 IT** 即时获取经营洞察

### ⏰ 自动化报表

与定时任务模块联动，按日 / 周 / 月自动巡检关键业务指标，按模板周期性生成 Excel / Word 报告并推送，实现**「无人值守问数 → 取数 → 出报表」**全链路闭环。

### 📚 知识库共享协同

将员工个人知识沉淀为组织资产，打破信息孤岛，实现知识的流转与复用：

- **个人知识库一键共享**：员工可将个人私有知识库共享至团队 / 部门，知识从"个人经验"升级为"组织能力"
- **全格式智能处理**：支持 PDF / Word / Excel / PPT / 图片等主流格式，自动完成向量化、Wiki 结构化与知识图谱构建
- **精准智能问答**：基于结构化知识库的高精度检索与问答，快速定位核心信息，精准解答业务问题
- **分级权限管控**：共享范围可按团队 / 项目 / 部门灵活配置，知识可见性精细可控，兼顾开放协作与信息安全

> **组织价值**：新员工入职即继承团队知识沉淀，不再重复"造轮子"；关键岗位知识不再随人员流动而丢失。

### 🛠 技能共享复用

将个人打造的高效 Skill 技能转化为团队共享资产，避免重复建设，加速能力复制：

- **个人 Skill 一键共享**：员工自定义的高频技能可发布至团队共享空间，供成员直接调用
- **OpenClaw Skills 标准化**：基于统一技能体系封装，确保技能跨团队、跨场景即插即用
- **技能市场化管理**：支持技能分类、搜索、版本管理与评价反馈，优质技能快速沉淀为组织标准能力
- **持续迭代进化**：团队成员可在共享技能基础上二次优化，形成"创建 → 共享 → 反馈 → 迭代"的正向循环

> **组织价值**：一人沉淀、全员复用——将个人最佳实践快速转化为组织标准化能力，人效倍增。

### 🤖 智能体共享赋能

将专属定制的智能体开放给团队，让每位成员都能获得专家级 AI 助手：

- **个人智能体一键共享**：员工根据业务场景定制的专属智能体（如门店经营助手、数据分析助手等），可共享至团队空间供成员直接使用
- **场景化智能体矩阵**：团队可按业务线沉淀多个垂直智能体，形成覆盖多场景的智能体能力池
- **配置即继承**：共享智能体完整保留 Prompt 设定、技能绑定、知识库关联等配置，使用者开箱即用
- **权限分级管控**：结合 RBAC 角色矩阵，智能体共享范围可按角色 / 部门精准授权，安全可控

> **组织价值**：业务专家的经验封装为智能体，一人定制、全团队受益，AI 能力从"个人工具"升级为"组织基座"。

## 七大模块

### 一、企业智能问数

打通 AI 与企业数据仓库的最后一公里，让「问数 · 取数 · 出报表」全程自然语言驱动：

- **多维分析引擎**：自动完成同比环比、趋势预测、归因分析，生成可视化结论
- **企业数据源直连**：一键配置 MySQL / BI 仓库，AES-256-GCM 加密，读写分离，连接池管理
- **精准 Text-to-SQL**：结合 Schema 元数据 + 字段释义 + Few-shot 示例，口语化提问自动转化为准确 SQL
- **一键 Excel 报表**：字段自动映射、格式化（千分位 / 百分比 / 日期）、多 Sheet 汇总与样式模板
- **报表自动推送**：联动定时任务，按周期自动生成并推送报表给指定成员
- **安全合规**：租户隔离、SQL 白名单、只读账号、审计日志、沙箱化执行

### 二、智能对话

平台核心交互窗口，承担所有 AI 能力的输出与调度：

- **多元交互**：支持切换各类智能体、图片 / 多格式附件上传、联网模式
- **ReAct 推理**：「思考 → 执行 → 观察」闭环，自主拆解需求、分步执行，支持长上下文对话
- **全场景办公**：调用技能库实现数据查询、文档生成、文稿撰写、报表生成等
- **透明可追溯**：流式生成 + 完整思考链路与工具调用可视化，全程可复盘
- **沙箱隔离**：所有技能、工具调用均在独立沙箱执行，用户数据互不交叉

### 三、智能体管理

兼顾开箱即用与个性化拓展：

- **默认智能体**：ReAct 推理智能体 + 业务咨询智能体，覆盖基础办公与逻辑处理
- **自定义智能体**：按业务场景定制（门店经营助手、数据分析助手、知识问答助手等）
- **企业级治理**：租户隔离 + RBAC 权限矩阵，分级分配与管控

### 四、技能管理

基于 **OpenClaw Skills** 理念的可自定义、可自动化技能调度体系：

- **智能调度**：自动识别、调用平台 Skill，无需手动配置
- **自定义技能**：将高频重复工作封装为 Skill，交由智能体全自动执行
- **文档生成能力**：内置 Word / Excel / PPT / HTML 生成引擎，分钟级输出规范文档
- **预置技能库**：业务数据查询、店铺经营分析、文档解析等开箱即用（`skills/preloaded/`）

### 五、智能知识库

一站式私有知识库，践行「知识即服务」：

- **全格式适配**：PDF / Word / Excel / PPT / TXT / 图片 / CSV / JSON / HTML / Markdown 一键上传
- **智能化处理**：自动向量化 + Wiki 结构化排版 + 知识图谱关联构建
- **协同共享**：一键共享个人知识库，团队复用与协作流转
- **精准问答**：基于结构化知识库的高精度智能检索与问答

### 六、定时任务自动化

无人值守的周期性任务全自动执行：

- **灵活配置**：自定义日 / 周 / 月周期，绑定 Skill 与智能体
- **自动报表**：联动问数 + 文档生成，按周期自动生成 Excel / Word 报告并推送
- **多场景覆盖**：定时抓取资讯、自动生成经营周报 / 月报、会员转化分析等
- **可靠保障**：沙箱隔离执行、超时控制、自动重试（默认 3 次）、租户隔离与配额管理

**创建定时任务（REST 示例）：**

```http
POST /api/v1/scheduled-tasks
Content-Type: application/json

{
  "name": "门店经营日报",
  "agent_id": "agent_xxx",
  "prompt": "基于知识库总结昨日门店经营情况并给出行动建议。",
  "schedule_type": "daily",
  "schedule_time": "08:00",
  "enable_sandbox": true,
  "max_retries": 3
}
```

### 七、团队共享空间

兼顾协同效率与数据安全的团队协作空间：

- **个性化空间**：以项目 / 部门为维度创建独立共享空间
- **资源集中管理**：沉淀业务知识、自定义技能、办公文档，团队统一共享
- **数据级隔离**：不同空间数据独立，杜绝泄露与混淆风险

## 系统架构

采用**前后端分离 + 模块化微服务**设计，每一环节均可替换、可拓展，支持本地与私有云部署。

### 运行时组件

| 组件             | 技术栈                                            | 职责                                  |
| ---------------- | ------------------------------------------------- | ------------------------------------- |
| 前端 Web UI      | Vue 3 + Nginx（`/cloudclaw-ui`）                  | 交互界面，端口 `80`                   |
| 后端服务         | Go 1.26 + Gin（`/cloudclaw-app`）                 | 业务 API 与编排，端口 `8080`          |
| 文档解析         | `/cloudclaw-docreader`                            | gRPC 文档解析服务，端口 `:50051`      |
| 主数据库         | PostgreSQL / ParadeDB（pg17）                     | 主存储，内置 pgvector + BM25 全文检索 |
| 缓存与队列       | Redis 7 + Asynq                                   | 缓存、异步任务队列、定时任务调度      |
| 技能沙箱         | `/cloudclaw-sandbox`                              | Docker 隔离执行 Agent Skill           |
| 向量库（可选）   | Qdrant / Milvus / Weaviate / Neo4j / Apache Doris | 图谱与多向量检索                      |
| 可观测（可选）   | Langfuse 3 + ClickHouse + MinIO                   | 全链路追踪与 Token 统计               |
| MCP 服务（可选） | `mcp` / `officecli-mcp`                           | MCP 网关与 Office 文档生成工具        |

### 生态兼容

| 维度     | 支持范围                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| 大模型   | OpenAI / Azure / Anthropic / DeepSeek / Qwen / 智谱 / 混元 / 豆包 / Gemini / MiniMax / NVIDIA / Ollama 等 **20+ 厂商** |
| 向量库   | PostgreSQL(pgvector) / Elasticsearch / OpenSearch / Milvus / Weaviate / Qdrant / Apache Doris / 腾讯云 VectorDB        |
| 对象存储 | 本地 / MinIO / AWS S3 / 火山引擎 TOS / 阿里云 OSS / 金山云 KS3 / 华为云 OBS                                            |
| IM 渠道  | 企业微信 / 飞书 / Slack / Telegram / 钉钉 / Mattermost / 微信                                                          |
| 搜索引擎 | DuckDuckGo / Bing / Google / Tavily / Baidu / Ollama / SearXNG                                                         |

### 企业级安全体系

| 维度        | 能力                                                                                |
| ----------- | ----------------------------------------------------------------------------------- |
| 🔐 数据安全 | 凭据 / API Key / 连接信息 **AES-256-GCM 静态加密**；私有化部署，数据不出企业边界    |
| 🏗️ 运行隔离 | Skill 与工具调用在 **Docker 沙箱**内执行；租户间数据独立隔离                        |
| 👥 权限治理 | **RBAC 四级角色**（Owner / Admin / Contributor / Viewer），空间分级隔离，SQL 白名单 |
| 📋 审计合规 | 操作全程可追溯，查询沙箱化执行，支持审计日志                                        |
| 🌐 通信安全 | gRPC TLS + Token 双向认证，**SSRF 防护**                                            |

## Docker 部署

### 环境要求

- [Docker](https://www.docker.com/) & [Docker Compose](https://docs.docker.com/compose/)
- [Git](https://git-scm.com/)

### 快速启动

```bash
git clone <your-repo-url> CloudClaw
cd CloudClaw
cp .env.example .env   # 按需编辑 .env
docker compose up -d   # 启动核心服务
```

启动成功后访问 **http://localhost** 即可使用。

### 可选服务（Profile）

| Profile    | 说明     | 启动命令                                  |
| ---------- | -------- | ----------------------------------------- |
| _(默认)_   | 核心服务 | `docker compose up -d`                    |
| `full`     | 全部功能 | `docker compose --profile full up -d`     |
| `neo4j`    | 知识图谱 | `docker compose --profile neo4j up -d`    |
| `minio`    | 对象存储 | `docker compose --profile minio up -d`    |

## 开发指引

### 快速开发模式（推荐）

```bash
make dev-start       # 启动基础设施（PostgreSQL / Redis / docreader 等）
make dev-app         # 新终端：本地启动后端
make dev-frontend    # 新终端：本地启动前端（热重载）
```

### Lite 模式（零外部依赖）

构建单文件二进制（SQLite + 内存队列），无需 PostgreSQL / Redis：

```bash
make build-lite      # 构建前端 + Go 二进制（SKIP_FRONTEND=1 可跳过前端）
make run-lite        # 以 .env.lite 默认值运行
make package-lite    # 打包可分发压缩包
```

详见 [`docs/LITE.md`](./docs/LITE.md)。
